
### 캔버스 관전과 발표

메인 캔버스 WebSocket의 `canvas_watch` 메시지를 브로커가 처리한다. `list`, `camera`, `follow`(`target_id`), `leave`, `start`, `stop`을 지원한다. 관전 대상 ID는 현재 방의 메인 연결마다 발급하며 다른 방의 ID·자기 자신·다른 대상을 관전하는 연결은 관전할 수 없다. 발표자는 방마다 한 명이다. 발표 시작은 `canvas_watch_invite`만 전송하며, 수락은 별도 `follow` 요청이므로 강제 관전하지 않는다. 늦게 접속한 참가자도 목록 조회 시 발표 안내를 받는다.

시점은 `{cx,cy,width,height,scale}` 세계 좌표 영역과 실제 확대율으로 전달하며, 브로커는 약 60ms보다 잦은 전달을 제한하고 실제 관전자에게만 카메라를 보낸다. 클라이언트는 변경된 시점을 약 80ms 간격으로 보내며 400ms 주기의 변경 확인으로 누락된 최종 시점을 복구한다. 관전 화면은 상대의 중심과 확대율을 그대로 적용하고 화면 크기에 따라 확대율을 다시 계산하지 않는다. 객체 내용과 권한을 복제하지 않으므로 각 참가자에게 허용된 객체만 계속 보인다. 발표 종료·대상 연결 종료 시 관전을 해제하며 관전자 화면은 기존 시점으로 돌아간다. 상태·초대·시점은 영속 저장하지 않는다. 관전 중 객체 변경·설정 변경·코드 실행 요청은 브로커에서도 거부한다(채팅과 조회는 유지).
